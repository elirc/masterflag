# Command Cheatsheet

All commands __inferred__ from repo scripts/READMEs/CI unless noted (see [verification-log.md](verification-log.md)). Run API commands from `api/`, frontend commands from `frontend/`.

## Whole platform

| Task | Command | Source |
| --- | --- | --- |
| Run everything (Docker) | `docker-compose -f docker-compose.yml up` (repo root) | [docker-compose.yml](../../docker-compose.yml) |
| Install git hooks | `make install-hooks` (repo root) | [AGENTS.md](../../AGENTS.md) |

## API (Django) — from `api/`

| Task | Command | Source |
| --- | --- | --- |
| Install deps | `make install` | [api/Makefile](../../api/Makefile) |
| Dev DB up + migrate | `make docker-up django-migrate` | [api/README.md](../../api/README.md) |
| Dev server | `make serve` | [api/README.md](../../api/README.md) |
| Dev server + task processor | `make serve-with-task-processor` | [api/README.md](../../api/README.md) |
| All tests | `make test` | [api/README.md](../../api/README.md); CI runs the same ([api-pull-request.yml](../../.github/workflows/api-pull-request.yml)) |
| Targeted tests | `make test opts='-k <expr>'` (add `-n0` for tiny subsets — xdist) | [api/README.md](../../api/README.md) |
| Lint (pre-commit, all hooks) | `make lint` | [api/Makefile](../../api/Makefile) |
| Typecheck (mypy strict) | `make typecheck` | [api/Makefile](../../api/Makefile) |
| Generate migrations | `make docker-up django-make-migrations` (prompts for a name — no auto-names) | [api/README.md](../../api/README.md) |
| Sync Flagsmith-on-Flagsmith flags | `python manage.py updateflagsmithenvironment` | [api/README.md](../../api/README.md) |

## What CI actually runs (PR gates)

- **API PRs** ([api-pull-request.yml](../../.github/workflows/api-pull-request.yml)): missing-migrations check, `make typecheck`, autogenerated-docs diff check, `make test` with coverage upload. Diff coverage requirement is **100%** ([api/README.md](../../api/README.md)).
- **Frontend PRs** ([frontend-pull-request.yml](../../.github/workflows/frontend-pull-request.yml)): `npm run test:unit`.
- **Platform PRs** ([platform-pull-request.yml](../../.github/workflows/platform-pull-request.yml)) plus Docker build/Trivy scan workflows.
