# 06 — Contribution Practice

Practice work sized junior → senior. Everything here follows the contribution-realism rule: useful, small blast radius, follows an existing pattern, testable, and honest about why a maintainer might reject it.

1. [01-good-first-tickets.md](01-good-first-tickets.md) — 16 junior tickets across the repo
2. [02-mid-level-feature-tickets.md](02-mid-level-feature-tickets.md) — 10 cross-layer tickets requiring design notes
3. [03-senior-build-projects.md](03-senior-build-projects.md) — 6 multi-week projects
4. [04-refactor-and-design-katas.md](04-refactor-and-design-katas.md) — senior katas with self-grading

Before any real PR: read [CONTRIBUTING.md](../../CONTRIBUTING.md), check the issue tracker for duplicates, and open an issue/discussion for anything beyond a trivial fix. **Some tickets below may already be fixed upstream by the time you read this — verifying that is part of the exercise.** Every ticket carries an "Interview story potential" line feeding [08-interview-prep/06](../08-interview-prep/06-behavioral-star-stories.md); a practice ticket you complete locally (without upstreaming) still produces the story.
