# 04 — Code Reading Gym

Reading is the job. These are workouts, not lectures — do them with the files open and a notebook.

1. [01-annotation-drills.md](01-annotation-drills.md) — 10 real excerpts to annotate (inputs, outputs, invariants, side effects, failure modes)
2. [02-trace-tables.md](02-trace-tables.md) — 5 traces to fill in step by step
3. [03-fake-code-contrasts.md](03-fake-code-contrasts.md) — 10 bad-vs-better pairs tied to real repo patterns
4. [04-review-katas.md](04-review-katas.md) — 9 fake PRs to review with graded findings

Rules of the gym: predict before you read; write your answer before checking the rubric; when you miss, write *why* you missed (wrong layer? unknown idiom? skipped the types?). Interviewers running code-review and debugging rounds are testing exactly these reflexes ([08-interview-prep/05](../08-interview-prep/05-debugging-and-code-review-rounds.md) turns four of these into timed simulations).
